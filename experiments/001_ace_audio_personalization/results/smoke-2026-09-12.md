# September 12, 2026 — synthetic pipeline smoke

**Outcome:** Passed locally on CPU. This is a pipeline wiring test, not a test of
ACE-Step weights, audio quality, or the RTX PRO 5000.

From the [experiment directory](../README.md), run:

```bash
uv sync --extra smoke
uv run --extra smoke maestro-ace smoke
uv run --extra smoke pytest -q
uv run --extra smoke ruff check .
```

The September 12 run prepared two synthetic 48 kHz examples in distinct
composition groups (one training, one validation); performed one PyTorch SFT
optimizer step; wrote four feedback candidates; made two human and two
automated preference pairs; performed one optimizer step for each preference
branch; and built two matched evaluation cases with four variants each.
The test suite reported **5 passed** and lint reported **All checks passed**.

The stand-in decoder, tensor preprocessor, audio renderer, and audio-energy
judge live in [smoke.py](../src/maestro_ace/smoke.py). The actual orchestration
uses the same [training](../src/maestro_ace/train.py),
[generation](../src/maestro_ace/generate.py),
[preference](../src/maestro_ace/preferences.py), and
[report](../src/maestro_ace/report.py) stages. Run-local files are written to
an ignored `artifacts/smoke/run-*/` directory and are not hosted on GitHub.

**Still unverified:** loading ACE checkpoints, ACE's audio preprocessing and
generation, CLAP judging, adapter compatibility, GPU memory/throughput, and
any musical improvement. The first real-ACE GPU smoke and original piano
recordings remain planned.
